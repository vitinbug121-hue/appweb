Documentação do Sistema

Conteúdo portado da documentação do sistema desktop original. O selo em cada item mostra se a funcionalidade já está disponível na versão web ou se ainda não foi portada.

Autenticação e Conexão

Autorizar ML
Realiza a conexão com a conta do Mercado Livre (fluxo OAuth completo), gerando o token de acesso e buscando o Seller ID automaticamente.
/ml/autorizar
Logar WhatsApp
Realiza a autenticação e conexão com o WhatsApp (via QR Code).
Não portado
Inserir Token MP / Token de Reembolso
Conecta a conta do Mercado Pago ao e-mail correspondente para identificar e conciliar boletos pagos, e cadastra os tokens usados para reembolso.
/configuracoes

Automação de Mensagens (WhatsApp e ML)

Primeira Msg e Wpp / Chamar Wpp
Envia a primeira mensagem com o prazo de entrega para novas vendas e captura o número de WhatsApp do cliente.
Não portado
Enviar Rastreio
Dispara uma mensagem com o código de rastreio (Correios ou AliExpress) para o comprador.
/vendas
Agradecimento
Envia uma mensagem de agradecimento aos clientes que já pagaram o boleto, com a previsão de entrega.
/vendas

Gestão de Boletos e Taxas

Enviar Boleto
Envia o boleto (aviso + código + pedido de comprovante) para quem ainda não recebeu a primeira cobrança. No sistema original só era enviado depois do rastreio — mesma regra aqui.
/vendas
Taxar e Autorizar BLT / Erro no Boleto / Cobrar Dobrado / Reenviar Boleto
Variações do fluxo de cobrança: notificar taxa e pedir autorização, corrigir código de barras com erro, cobrar uma segunda taxa, ou reenviar o boleto já emitido.
Não portado
Atualizar Pagos
Consulta o Mercado Pago (testando os tokens cadastrados em carrossel) e marca automaticamente os boletos que já foram pagos ou identifica os vencidos.
Dashboard / /acoes/atualizar-pagos

Inteligência Artificial (IA)

Responder Dúvidas ML
Usa IA (Groq) para responder automaticamente às perguntas feitas pelos usuários nos anúncios do Mercado Livre, com filtro de palavras sensíveis.
/ia
Rodar IA Reclamação / Rodar IA Comum
Executa a IA para analisar e responder reclamações abertas ou dúvidas gerais no chat comum — depende de diferenciar os dois tipos de conversa na API do ML.
Não portado

Dashboards, Relatórios e Dados

Dashboard
Painel geral de controle e monitoramento da conta ativa, com KPIs e log em tempo real.
/
Todos Pagos / Dash Lote
Gráficos analíticos de resultados financeiros e desempenho segmentado por lote de envio.
Não portado
Exportar Excel
Gera uma planilha com os dados de todas as vendas da conta, com link clicável e destaque para vendas encerradas.
/vendas

Pendências

Não Pagos / Não Autorizados
Cobra automaticamente os clientes que receberam o boleto/solicitação de autorização há mais de 24h e ainda não responderam.
Não portado

Controle do Sistema e Rotinas

Agendamentos
Cria e gerencia tarefas agendadas para rodar rotinas automaticamente, com histórico de execução.
/agendamentos
Stop Urgente
No sistema desktop original, interrompia um processamento longo e bloqueante em andamento. No modelo web, cada ação já é uma requisição isolada e rápida — esse botão hoje é mais simbólico do que funcional; vale reavaliar o que ele deveria fazer nesse novo modelo (ex: pausar o agendador).
